# 训练助手设计方案

## 定位与范围

- 本机使用的训练助手，当前重点是对话和工具调用。
- 支持理论知识问答、联网搜索、历史训练记录分析和个人水平分析。
- 暂不实现训练录入和独立记忆模块。

## 对话与会话

- 使用 Pi SDK 实现对话，模型自主判断是否调用可用工具。
- 对话中展示工具调用状态和联网搜索的来源链接。
- 使用 Pi 原生 JSONL session tree 保存对话，支持重启后继续对话。
- 界面提供会话列表，支持新建、切换、重命名和删除会话。

## 模型配置

- 模型配置由本项目独立管理，配置体验参考 pi-web。
- 支持 DeepSeek 和 OpenAI Chat Completions 兼容接口。
- 配置包含供应商、Base URL、模型 ID 和 API Key。

## 工具

### 理论知识

- 知识来源为项目中的 `健身理论.md` 和 `肌腱训练理论.md`。
- 模型按问题选择文档，按需读取整篇。

### 训练记录与个人水平

- 只读分析 `backend/训练日志.json` 中的历史训练记录。
- 根据问题查询相关记录，支持查询完整历史。
- 分析所需的信息缺失时，助手必须主动询问。
- 允许直接向云端模型发送回答所需的训练资料，无需提示或确认。

### 联网搜索

- 使用 Exa 作为搜索服务。
- 联网搜索默认关闭；用户在联网搜索模块配置 API Key 并开启后，模型可按需调用。
- 搜索结果在对话中展示来源链接。
